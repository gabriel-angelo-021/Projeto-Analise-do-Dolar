## 📌 Sobre o projeto

Projeto de análise de dados desenvolvido para explorar informações da rede hospitalar do Rio de Janeiro, utilizando dados públicos e aplicando técnicas de tratamento, organização, análise e visualização de dados.

O projeto foi desenvolvido com uma abordagem de dados em etapas, desde a preparação da base até a construção de indicadores e um dashboard interativo no Power BI.

O objetivo é transformar dados hospitalares em informações que facilitem a análise da estrutura e da distribuição dos recursos hospitalares.

---

## 🎯 Objetivos

- analisar a distribuição da rede hospitalar no Rio de Janeiro;
- identificar características dos estabelecimentos hospitalares;
- analisar a disponibilidade e distribuição de leitos;
- comparar informações relacionadas ao SUS e à rede não SUS;
- analisar a distribuição de leitos de UTI;
- criar indicadores para apoiar a interpretação dos dados;
- desenvolver um dashboard interativo no Power BI;
- utilizar SQL para consultas e análises;
- aplicar boas práticas de organização e tratamento de dados.

---

## 🧩 Problema de negócio

A grande quantidade de informações relacionadas à rede hospitalar pode dificultar a identificação de padrões e a comparação entre diferentes estabelecimentos e recursos disponíveis.

A proposta deste projeto foi organizar esses dados e transformá-los em informações visuais e indicadores que permitam uma análise mais objetiva da estrutura hospitalar do Rio de Janeiro.
